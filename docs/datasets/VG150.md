# VG150 Dataset Setup

## Sources

- HDF5: https://huggingface.co/datasets/kb-kim/LLM4SGG
- Vocabulary: https://github.com/Prk10/VG150_VisualGenome
- Metadata: https://homes.cs.washington.edu/~ranjay/visualgenome/data/dataset/

HDF5 SHA256:
`ad52a01f8e6142bb7bc62d91f97dad1567f44772a23eac68d60a5b7766ffe4b1`

## Step 1: Download

Run from repository root:

    bash scripts/download_vg150.sh

## Step 2: Generate manifest

    python scripts/build_vg150_manifest.py --h5 data/raw/vg150/VG-SGG-with-attri.h5 --metadata data/raw/vg150/image_data_raw.json --output-dir data/raw/vg150

## Expected split counts

For the current preprocessing policy:

- Train: 57,723
- Validation: 5,000
- Test: 26,446

Full equivalence with the original community split is not yet verified.

## Dataset layout

    data/raw/vg150/
        VG-SGG-with-attri.h5
        VG-SGG-dicts-with-attri.json
        image_data.json.zip
        image_data_raw.json
        image_data.json
        splits.json

## Notes

- Do not commit downloaded data.
- No JPEG images are needed for geometry-only features.
- Never randomly resplit the benchmark.
- Do not mix dataset variants without verifying compatibility.
- The manifest generator does not overwrite existing outputs.
