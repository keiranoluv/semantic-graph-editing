# Nhiệm vụ 2B · Dự đoán thao tác chỉnh sửa đồ thị

Mô hình nhận đồ thị nguồn và câu yêu cầu, dự đoán thao tác và áp thao tác để tạo đồ thị đích.

- [MagicBrush](magicbrush/README.md) có bộ cặp, lệnh train GNN, suy luận trực tiếp và chấm test.
- [He và cộng sự](he2020/README.md) là thực nghiệm mở rộng với MLP/GNN và đồ thị truy vấn crowdsourced.

Các thao tác và quy tắc kiểm tra đồ thị dùng chung nằm trong common/editing/. Các README được đọc với thư mục làm việc là gốc submission/.
